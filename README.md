# Self Rein Tracker

Telegram-бот для ежедневного трекинга двух пользователей с разными наборами
показателей, раздельными данными и персональными веб-дашбордами.

Система уже включает:

- ввод данных командами и голосовыми сообщениями;
- отдельные профили Паши и Светы;
- статистику, стрики и недельные отчёты;
- учёт финансов Паши с категориями расходов;
- защищённые паролями веб-дашборды;
- ежедневные резервные копии SQLite;
- напоминания и автоматические отчёты;
- OpenAI-совместимый LLM/ASR-пайплайн с локальным Whisper-фолбэком.

## Профили пользователей

Данные пользователей изолированы по Telegram ID. Профиль определяет поля,
подсказки, напоминания, отчёты и содержимое дашборда.

### Паша

Локальный часовой пояс: `Asia/Vladivostok`.

| Показатель | Формат |
|---|---|
| Подъём | время `HH:MM` |
| Засыпание | время `HH:MM` |
| Алгоритмы | минуты или `нет` |
| Системный дизайн | минуты или `нет` |
| Тренировка | да/нет |
| Эмоциональное состояние | 1–10 |
| Доходы, расходы и накопления | сумма, валюта, категория, комментарий |

Для финансов дополнительно считаются:

- доход и расход за период;
- сумма, отложенная в накопления;
- накопленный капитал;
- доля накоплений от дохода;
- распределение расходов по категориям;
- ежемесячный финансовый итог и AI-анализ при настроенном LLM API.

### Света

Локальный часовой пояс: `Asia/Irkutsk`.

| Показатель | Формат |
|---|---|
| Подъём | время `HH:MM` |
| Засыпание | время `HH:MM` |
| Тренировка | да/нет |
| Прогулка | да/нет |
| Учёба | да/нет |
| Полезное занятие | свободное описание |
| Эмоциональное состояние | 1–10 |
| Сладкое | да/нет |
| Алкоголь | да/нет |

Полезным занятием может быть литература, обучающее YouTube-видео, курс или
любая другая полезная активность.

## Telegram-команды

| Команда | Назначение |
|---|---|
| `/d [дата] ключ значение …` | записать или дополнить день |
| `/m ±сумма категория комментарий` | финансы Паши |
| `/s` | сегодняшний день, недельная статистика и стрики |
| `/w [n]` | получить Markdown-отчёт за `n` дней |
| `/undo` | удалить последнюю заметку или денежную операцию |
| `/help` | персональная шпаргалка пользователя |
| любой обычный текст | сохранить заметку |
| голосовое сообщение | распознать, разобрать и предложить подтверждение |

Дата в `/d` необязательна. Без неё используется локальная дата пользователя:
Владивосток для Паши и Иркутск для Светы. Повторная команда за ту же дату
дополняет запись и не стирает остальные поля.

### Примеры для Паши

```text
/d подъем 7:30 отбой 23:40 алго 60 системы 30 трен состояние 8
/d алго нет системы 45 трен нет состояние 6
/d 2026-09-18 подъем 8:10 состояние 7
```

### Примеры для Светы

```text
/d подъем 8:00 отбой 23:30 трен прогулка учеба состояние 8
/d сладкое нет алкоголь нет полезное книга по психологии
/d прогулка нет учеба состояние 6 полезное обучающее видео по дизайну
```

`полезное` забирает остаток сообщения, поэтому это поле следует писать
последним.

Булевы значения понимают формы `да/нет`, `1/0`, `+/-`, `y/n`,
`true/false`. Тренировку также можно записать словами `зал`, `бег`, `улица`,
`турник` или `отдых`.

### Финансы Паши

```text
/m +250000 зарплата сентябрь
/m -1200 еда обед в кафе
/m -3500 транспорт такси
/m =100000 накопления
/m =5000$ холодный кошелёк
```

Обозначения:

- `+` — доход;
- `-` — расход;
- `=` — перевод в накопления;
- сумма может содержать `₽`, `$`, `€`, `USDT` или `BTC`;
- первое слово после суммы становится категорией;
- остаток строки сохраняется как комментарий.

В дашборде сумма расходов за день кликабельна. По ней открываются категории и
отдельные операции этого дня.

## Голосовой ввод

Пайплайн:

```text
Telegram voice
  → OpenAI gpt-transcribe (если задан API-ключ)
  → GPT/OpenAI-compatible JSON parser
  → regex-дополнение и проверка профиля
  → карточка подтверждения
  → запись после нажатия кнопки
```

Если облачная транскрибация недоступна, используется локальный
`faster-whisper`. Если LLM недоступна, остаётся regex-парсер. Перед сохранением
бот показывает результат и кнопки:

- «Записать»;
- «Отменить»;
- «Показать текст».

Поля другого пользователя и финансы не могут попасть в профиль Светы: итог
голосового разбора фильтруется по профилю перед подтверждением.

Сырая транскрипция, разобранный JSON и уровень парсинга сохраняются в таблице
`voice`.

## Дашборды

Дашборд встроен в Go-бинарник и читает ту же SQLite. Отдельный frontend или
Node.js не нужны.

Возможности:

- периоды 7, 30, 90 и 365 дней;
- профильные показатели пользователя;
- среднее эмоциональное состояние и график 1–10;
- персональные стрики;
- последние дневные записи;
- финансы и детализация расходов только для Паши;
- отдельный логин и пароль для каждого пользователя.

Backend слушает только `127.0.0.1`, а Caddy предоставляет HTTPS. Текущий адрес:

<https://dash.78-17-106-90.sslip.io>

Авторизация — HTTP Basic Auth поверх HTTPS.

## Отчёты и стрики

`/s` показывает короткую сводку за сегодня и неделю.

Стрики Паши:

- алгоритмы;
- системный дизайн;
- тренировки;
- заполненные дни.

Стрики Светы:

- учёба;
- прогулки;
- тренировки;
- полезные занятия.

`/w` отправляет Markdown-файл. Отчёт содержит только поля профиля:

- режим сна;
- активность и развитие;
- эмоциональное состояние;
- питание Светы или финансы Паши;
- таблицу по дням;
- заметки за период.

Незакрытый сегодняшний день не обрывает текущий стрик.

## Автоматическое расписание

Общие задачи рассчитываются в `TZ`, а ежедневное напоминание — отдельно в
локальном часовом поясе пользователя.

| Когда | Действие |
|---|---|
| ежедневно в 22:00 Владивостока | напомнить Паше внести итоги |
| ежедневно в 22:00 Иркутска | напомнить Свете внести итоги |
| воскресенье в `WEEKLY_REPORT` | отправить недельный отчёт |
| 5-го числа | напомнить Паше записать зарплату |
| 20-го числа | напомнить Паше записать аванс |
| 1-го числа | прислать Паше итог финансов прошлого месяца |
| ежедневно в `DAILY_BACKUP` | создать и отправить резервную копию |

Суммы зарплаты и аванса не создаются автоматически: бот просит записать
фактическую сумму.

Планировщик хранит дату последнего запуска каждой задачи в SQLite, поэтому
перезапуск сервиса не создаёт повторных уведомлений.

## Хранение и резервные копии

Основное хранилище — SQLite:

```text
/opt/tracker/data/tracker.db
```

Основные таблицы:

- `days` — профильные показатели по пользователю и дате;
- `money` — доходы, расходы и накопления;
- `notes` — обычные заметки;
- `voice` — транскрипции и результаты голосового разбора;
- `jobs` — состояние планировщика;
- `schema_migrations` — выполненные миграции.

Все записи содержат `user_id`. Для `days` используется составной ключ
`(user_id, date)`.

Ежедневный бэкап:

1. создаётся консистентно через `VACUUM INTO`;
2. хранится локально 30 дней;
3. отправляется главному пользователю в Telegram;
4. включает данные обоих пользователей.

## Конфигурация

Пример находится в [`deploy/bot.env.example`](deploy/bot.env.example).

### Обязательные переменные

```dotenv
BOT_TOKEN=123456:telegram-token
OWNER_ID=949465743
TZ=Europe/Moscow
PASHA_TZ=Asia/Vladivostok
SVETA_TZ=Asia/Irkutsk
DATA_PATH=/opt/tracker/data/tracker.db
```

### Пользователи

```dotenv
TRACKER_USERS=949465743:Паша:pasha:pasha-login:password-1,908821693:Света:sveta:sveta-login:password-2
```

Формат:

```text
telegram_id:имя:профиль:логин_дашборда:пароль
```

Доступные профили: `pasha`, `sveta`.

### Голос и LLM

```dotenv
ASR_URL=http://127.0.0.1:8081/transcribe
LLM_API_KEY=
LLM_BASE_URL=https://api.openai.com/v1
LLM_MODEL=gpt-5.4-mini
TRANSCRIBE_MODEL=gpt-transcribe
OLLAMA_URL=http://127.0.0.1:11434
OLLAMA_MODEL=qwen2.5:7b-instruct
```

При наличии `LLM_API_KEY` облачная транскрибация используется первой, а
локальный Whisper остаётся фолбэком. Без API-ключа основным ASR становится
локальный сервис.

### Дашборд, расписание и бэкапы

```dotenv

BACKUP_DIR=/opt/tracker/data/backups
DAILY_BACKUP=04:00
DAILY_REMINDER=22:00
WEEKLY_REPORT=12:40
WEEKLY_REPORT_DAYS=7
INCOME_REMINDER=10:00
MONTHLY_FINANCE=10:15
```

## Архитектура

```text
cmd/bot             запуск приложения и graceful shutdown
internal/model      поля дня, профили и валидация
internal/config     переменные окружения и пользователи
internal/store      SQLite, миграции и бэкапы
internal/parse      /d, /m и regex-разбор речи
internal/asr        локальная и OpenAI-совместимая транскрибация
internal/llm        JSON-схема, LLM-парсер и AI-анализ
internal/bot        Telegram-хендлеры и подтверждения
internal/report     статистика, стрики и Markdown-отчёты
internal/dashboard  защищённый read-only веб-интерфейс
internal/scheduler  ежедневные и календарные задачи
internal/tg         Telegram Bot API
asr/                FastAPI + faster-whisper
deploy/             systemd unit и пример env
```

Структура `model.Day` — единый источник полей. Из неё формируются:

- SQLite-колонки;
- ключи `/d`;
- JSON-схема LLM;
- профильная `/help`;
- список незаполненных полей.

## Локальная разработка

Требуется Go 1.25+.

```sh
make test
make vet
make build
```

Эквивалентные команды:

```sh
go test ./...
go vet ./...
CGO_ENABLED=0 go build -trimpath -ldflags="-s -w" -o tracker-bot ./cmd/bot
```

Локальный ASR:

```sh
cd asr
docker compose up -d --build
curl http://127.0.0.1:8081/health
```

## Деплой

Приложение запускается как `systemd`-сервис:

```sh
make build
scp tracker-bot root@server:/opt/tracker/tracker-bot
scp deploy/tracker-bot.service root@server:/etc/systemd/system/

ssh root@server
systemctl daemon-reload
systemctl enable --now tracker-bot
systemctl status tracker-bot
```

Переменные окружения находятся в:

```text
/etc/tracker/bot.env
```

После обновления:

```sh
systemctl restart tracker-bot
journalctl -u tracker-bot -n 100 --no-pager
curl http://127.0.0.1:8080/healthz
```

Схема SQLite дополняется новыми профильными колонками при старте.

## Безопасность

- бот принимает сообщения только от ID из `TRACKER_USERS`;
- данные разделены по `user_id`;
- dashboard backend не открыт напрямую в интернет;
- пароли передаются только через HTTPS;
- у каждого пользователя отдельные dashboard credentials;
- финансы Паши не отображаются Свете;
- подтверждение защищает от ошибочного сохранения голосового разбора;
- ежедневная копия отправляется только `OWNER_ID`;
- env-файл должен иметь права `0600`.
